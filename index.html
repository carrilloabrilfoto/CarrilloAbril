Sí, se puede filtrar por etiqueta

Esto es código funcionando, no un mockup: un eje de categoría (Registro social / Negativo+color / Portadas) que se puede combinar con un segundo eje transversal (Retratos), igual a como lo charlamos. Probá los botones.

Esto es un prototipo, no el portfolio final. Los cuadros de abajo son marcadores de posición generados con CSS —no fotos reales— para poder mostrar cómo se comporta el filtro. Cuando tengas las imágenes definitivas, cada marcador se reemplaza por la foto y conserva sus mismas etiquetas.
Solo retratos

Categoría vs. etiqueta

Los pills de arriba (Registro social, Negativo+color, Portadas) son la estructura narrativa: cada foto pertenece a una sola. El switch "Retratos" es una etiqueta transversal (data-tags="retrato"): puede estar prendida sobre cualquier categoría a la vez, sin romper el recorrido registrar → intervenir.

Ver proceso

En las piezas de Intervención digital, "ver proceso" despliega la tira base → intervención → resultado que mencionaste, como capa opcional en vez de mostrarla siempre — así la imagen final sigue siendo la protagonista.

Cómo reemplazar las fotos

Cada tarjeta vive en el array items al final del archivo. Cambiá el ícono de placeholder por <img src="tu-foto.jpg">, ajustá title y tags, y el filtro sigue funcionando igual.
